# How to help Halcyon

Thank you for wanting to help! Halcyon was built by a non-programmer with AI
assistance, so please be kind and explain things simply.

## Quick start

- **The app:** [latest release installer](https://github.com/hamamun/HALCYON/releases/latest) — `Halcyon-Setup.exe`, Windows 10/11 x64
- **The stack:** Python 3.12, PySide6 / Qt Quick (QML), libVLC 3.0.21
- **Run from source:** see [docs/BUILDING.md](docs/BUILDING.md)

## Ways to help

1. **Test** — install the app, use it, report anything odd in Issues.
2. **Fix** — pick an issue labelled `help wanted` or `good first issue`, or
   open a new issue first and say you would like to fix it.
3. **Review** — comment on open pull requests; a second pair of eyes is gold
   in this project.

## Rules (short)

- Explain your change in simple words in the pull request.
- Ask before adding anything that connects to the internet or sends data
  anywhere.
- By contributing, you agree your contribution can be used in Halcyon under
  this repository's [LICENSE](LICENSE).
- Be patient and kind — the maintainer is not a programmer.

## The fun part

Every change merged to `main` automatically builds a fresh
`Halcyon-Setup.exe`. Download it from the Releases page and see your work
shipped. 🚀
